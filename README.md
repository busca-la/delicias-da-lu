# Delícias da Lu

Site estático da Delícias da Lu, recuperado da implantação existente na Vercel.

## Estrutura

- `index.html`: página e animações (HTML, CSS e JavaScript).
- `assets/`: imagens e fontes auxiliares da página.

## Publicação

Vercel: selecionar **Other** como framework, raiz do repositório como pasta do projeto, sem comando de build e sem diretório de saída especial. O arquivo `index.html` está na raiz.

O projeto não exige Node.js, `npm install` nem serviços pagos. Não insira informações comerciais não confirmadas.
